# Math Game

A terminal-based math game for kids built in Python.

## Features

- Addition, subtraction, and multiplication practice
- 3 difficulty levels
- 3 attempts per question
- Persistent stats tracking (accuracy, streaks, best score)
- Random ASCII art animals on exit

## Requirements

- Python 3.x
- cowsay
- pyfiglet

## Installation

```bash
pip install cowsay pyfiglet
```

## Usage

```bash
python main.py
```
